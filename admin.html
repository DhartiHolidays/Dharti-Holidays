How it works

1. Download the template below and fill it in — one row per hotel, in Excel or Google Sheets.
2. Save it as a CSV file (File → Download → Comma Separated Values in Google Sheets, or "Save As CSV" in Excel).
3. Upload it here. Every hotel is added as already approved — no review step, since you're adding it yourself.
4. If a Destination in your file doesn't exist yet, it's created automatically.

Step 1 — Get the template

Columns: Destination, Region (domestic/international), Hotel Name, City/Area, Category (Budget/Deluxe/Luxury), Price Per Night, Rating, Amenities (comma-separated), Google Maps Link, Photo URL (all except Destination, Region, Hotel Name, Category, Price are optional).
